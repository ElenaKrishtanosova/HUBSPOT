HubSpot CRM Database Schema - Simplified Version

Core Tables:

1. companies
   - company_domain (PK, unique)
   - name
   - industry (Retail, Wholesale, Manufacturing, Distribution)

2. contacts
   - contact_email (PK, unique)
   - first_name
   - last_name
   - company_domain (FK → companies.company_domain)

3. deals
   - deal_id (PK, BIGSERIAL)
   - deal_name
   - deal_stage (Appointment Scheduled, Qualified to Buy, Presentation Scheduled, Closed Won, Closed Lost)
   - description
   - contact_email (FK → contacts.contact_email)
   - company_domain (FK → companies.company_domain)
   - activity_date (TEXT)

4. tickets
   - ticket_id (PK, BIGSERIAL)
   - ticket_name
   - priority (Low, Medium, High)
   - issue_of_interest (Crumb tray, Overheating, Wi‑Fi setup, Shipping delay, Thermostat, Packaging, Noise, Invoice)
   - description
   - contact_email (FK → contacts.contact_email)
   - company_domain (FK → companies.company_domain)
   - ticket_owner (FK → users.email)
   - activity_date (TEXT)

5. products
   - product_id (PK, BIGSERIAL)
   - name (unique)
   - description
   - price

6. users
   - user_id (PK, BIGSERIAL)
   - email (unique)
   - full_name

Activity Tables:

7. tasks
   - task_id (PK, BIGSERIAL)
   - title
   - notes
   - assigned_to_user_id (FK → users.user_id)
   - deal_id (FK → deals.deal_id)

8. calls
   - call_id (PK, BIGSERIAL)
   - notes
   - direction
   - assigned_to_user_id (FK → users.user_id)
   - contact_email (FK → contacts.contact_email)
   - activity_at (TIMESTAMPTZ)

9. emails
   - email_id (PK, BIGSERIAL)
   - body
   - subject
   - contact_email (FK → contacts.contact_email)
   - direction
   - created_at (TIMESTAMPTZ)

10. notes
    - note_id (PK, BIGSERIAL)
    - body
    - activity_assigned_to_user_id (FK → users.user_id)
    - contact_email (FK → contacts.contact_email)
    - deal_id (FK → deals.deal_id)
    - ticket_id (FK → tickets.ticket_id)
    - activity_date (DATE)

Association Tables:

11. deal_line_items
    - deal_id (FK → deals.deal_id)
    - product_id (FK → products.product_id)
    - quantity
    - unit_price

12. company_contact_associations
    - company_domain (FK → companies.company_domain)
    - contact_email (FK → contacts.contact_email)

13. deal_company_associations
    - deal_id (FK → deals.deal_id)
    - company_domain (FK → companies.company_domain)

Key Changes from Previous Schema:
- All ID fields now use BIGSERIAL for proper auto-increment functionality
- Simplified structure without vector embeddings
- Removed complex fields and constraints
- Streamlined associations without labels
- Focus on essential fields for business insights generation
