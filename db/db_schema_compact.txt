HubSpot CRM Schema - Simplified Compact Version

companies: company_domain(PK), name, industry
contacts: contact_email(PK), first_name, last_name, company_domain(FK)
deals: deal_id(PK, BIGSERIAL), deal_name, deal_stage, description, contact_email(FK), company_domain(FK), activity_date
tickets: ticket_id(PK, BIGSERIAL), ticket_name, priority, issue_of_interest, description, contact_email(FK), company_domain(FK), ticket_owner(FK), activity_date
products: product_id(PK, BIGSERIAL), name(UK), description, price
users: user_id(PK, BIGSERIAL), email(UK), full_name
tasks: task_id(PK, BIGSERIAL), title, notes, assigned_to_user_id(FK), deal_id(FK), created_at
calls: call_id(PK, BIGSERIAL), notes, direction, assigned_to_user_id(FK), contact_email(FK), activity_at
emails: email_id(PK, BIGSERIAL), body, subject, contact_email(FK), direction, created_at
notes: note_id(PK, BIGSERIAL), body, activity_assigned_to_user_id(FK), contact_email(FK), deal_id(FK), ticket_id(FK), activity_date
deal_line_items: deal_id(FK), product_id(FK), quantity, unit_price

Associations:
company_contact: company_domain(FK), contact_email(FK)
deal_company: deal_id(FK), company_domain(FK)

Constraints:
industry IN ('Retail', 'Wholesale', 'Manufacturing', 'Distribution')
deal_stage IN ('Appointment Scheduled', 'Qualified to Buy', 'Presentation Scheduled', 'Closed Won', 'Closed Lost')
priority IN ('Low', 'Medium', 'High')
issue_of_interest IN ('Crumb tray', 'Overheating', 'Wi‑Fi setup', 'Shipping delay', 'Thermostat', 'Packaging', 'Noise', 'Invoice')

Key Features:
- All ID fields use BIGSERIAL for auto-increment
- Simplified structure without vector embeddings
- Essential fields only for business insights
- Support for incremental data insertion
- All date fields use TIMESTAMPTZ for consistency and time-based filtering
