# Database Management

Эта папка содержит все файлы, связанные с управлением базой данных HubSpot CRM.

## 📁 Структура файлов

### 🏗️ Создание и настройка
- **`create_schema.py`** - Основной скрипт создания схемы базы данных
- **`setup_local_db.sh`** - Автоматический скрипт настройки локальной PostgreSQL

### 🧪 Тестирование
- **`test_db.py`** - Тесты подключения, схемы и векторных операций
- **`demo_vectors.py`** - Демонстрация векторного поиска

### 📊 Генерация контекста для LLM
- **`generate_db_context.py`** - Детальная схема в Markdown формате
- **`generate_compact_context.py`** - Компактная схема для быстрого понимания
- **`generate_json_context.py`** - JSON схема для программного использования

### 📋 Сгенерированные файлы
- **`db_schema_context.md`** - Полная схема с типами данных и ограничениями
- **`db_schema_compact.txt`** - Компактная схема без векторных полей
- **`db_schema_context.json`** - Структурированная JSON схема
- **`db_schema_simple.txt`** - Ультра-простая схема для LLM контекста

## 🚀 Быстрый старт

### 1. Настройка базы данных
```bash
cd db
./setup_local_db.sh
```

### 2. Создание схемы вручную
```bash
cd db
uv run python create_schema.py
```

### 3. Тестирование
```bash
cd db
uv run python test_db.py
```

### 4. Генерация контекста для LLM
```bash
cd db
uv run python generate_compact_context.py  # Компактная схема
uv run python generate_json_context.py     # JSON схема
```

## 📊 Типы схем

### Детальная схема (`db_schema_context.md`)
- Полная информация о типах данных
- Все ограничения (PK, FK, Unique)
- Подробное описание каждой таблицы

### Компактная схема (`db_schema_compact.txt`)
- Основные поля (без ID и векторных полей)
- Ключевые связи между таблицами
- Краткое описание структуры

### JSON схема (`db_schema_context.json`)
- Структурированные данные для программного использования
- Полная информация о связях
- Машинно-читаемый формат

### Простая схема (`db_schema_simple.txt`)
- Только названия таблиц и основные поля
- Ключевые отношения в одну строку
- Минимальный контекст для LLM

## 🔧 Конфигурация

Все скрипты используют настройки из `../config.yaml`:
- Параметры подключения к базе данных
- Настройки векторных полей
- Параметры логирования

## 📝 Примечания

- Все скрипты автоматически исключают векторные поля при генерации схемы
- Фокус на структуре данных и взаимосвязях таблиц CRM
- Готовые файлы схемы можно использовать как контекст для LLM моделей
